# microTransfer 0.1.0

Initial public release of the study-aware transferability framework used in
the associated mSystems Research Article.

The release contains:

- an R package implementing membership, response, prediction, and evidence
  classification workflows;
- leave-one-study-out and matched-null validation utilities;
- tests and a worked vignette;
- analysis scripts for the *Vaccinium*, rice, Arabidopsis, and FAPROTAX
  evaluations;
- source-data identifiers and integrity manifests for external datasets.

No raw sequencing reads or unpublished personal data are included.
